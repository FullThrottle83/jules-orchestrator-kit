# v0.27.0 Platform Evolution & Architecture Specification

## Executive Overview

The v0.27.0 architecture expands `jules-orchestrator-kit` from core task execution into full lifecycle autonomy. It introduces:
1. **PR Review Auto-Remediation (`src/review-repair.mjs`, `agentctl review-repair`):** Parses human GitHub PR review comments (`CHANGES_REQUESTED`), filters conversational praise (`lgtm`, `looks good`), maps line/file coordinates, and synthesizes OODA repair task envelopes.
2. **Multi-Provider Failover Router (`createFailoverProvider` in `src/provider.mjs`):** Intercepts HTTP 429 rate limits and 5xx unavailability, appends telemetry audit entries, and routes execution to secondary providers.
3. **Zero-Dependency Local Telemetry Dashboard (`src/dashboard.mjs`, `agentctl dashboard`):** A lightweight `node:http` server serving a real-time dark-mode HTML visualizer and REST JSON endpoints (`/api/telemetry`, `/api/flaky`, `/api/locks`, `/api/status`).

---

## 1. PR Review Auto-Remediation (`agentctl review-repair`)

`parseReviewComments(input)` parses raw JSON comment streams and filters out non-actionable reviews:

```bash
agentctl review-repair pr-comments.json
```

- Skips `APPROVED`, `DISMISSED`, or `isResolved === true` threads.
- Rejects conversational praise via regex (`/^(?:lgtm|looks good|nice|awesome|thanks)[\s.!]*$/i`).
- Synthesizes task envelopes target-scoped to modified file lines.

---

## 2. Multi-Provider Failover & Rate Limit Resilience

`createFailoverProvider(providers, config)` manages fallback LLM routing:

```javascript
import { createFailoverProvider } from "./src/provider.mjs";

const provider = createFailoverProvider(["jules", "claude-code", "codex"]);
const result = await provider.dispatch(task);
// Automatically falls over on HTTP 429 or 5xx status codes
```

---

## 3. Zero-Dependency Local Dashboard (`agentctl dashboard`)

`startDashboardServer(port, root)` serves real-time status and audit views on `http://localhost:4100`:

```bash
agentctl dashboard 4100
```

- `GET /`: Dark-mode HTML/CSS/JS telemetry visualizer.
- `GET /api/status`: Platform version and environment status.
- `GET /api/telemetry`: SHA-256 hash-chained log events and verification status.
- `GET /api/flaky`: Wilson-Score statistical test quarantine ledgers.
- `GET /api/locks`: Active VFS mutex lock status.
