# Jules Web Workspace Preset

`jules-init` generates an encoded workspace preset for the Jules web UI in
this file. Jules web UI: https://jules.google (the preset format is maintained
by this kit). No workspace-specific token is checked in here; run initialization
in the target workspace to generate one.

The kit-generated format is `JULES1.<sha256>.<base64url-brotli-json>`:
- `sha256` is the digest of the uncompressed JSON workspace manifest.
- The payload is Brotli-compressed JSON encoded as base64url.

This is a convenience preset generated by this kit, not an official Google
setup code, credential, or endorsement. Encoding is not encryption, and the
digest is not an authenticated signature. Review the decoded settings before
use; do not treat the token as a secret-storage mechanism.
